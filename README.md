# ServiceNow Project - Import Data using Transform Maps

## Project Title
Import Data using Transform Maps (Spreadsheet)

## Objective
The objective of this project is to import structured employee data from a spreadsheet into ServiceNow using Import Sets and Transform Maps.

## Project Phases

### Phase 1 - Project Setup
Prepared the sample employee spreadsheet for importing into ServiceNow.

### Phase 2 - Create Custom Table
Created the custom Employee Test table with the required employee fields:
- Employee ID
- Employee Name
- Email
- Department
- Location

### Phase 3 - Create Import Set Table
Created the Employee Import table and loaded the spreadsheet data.

### Phase 4 - Create Transform Map
Created the Sample Spreadsheet Import Transform Map between the Employee Import and Employee Test tables.

### Phase 5 - Transform and Validate
Transformed the imported data and verified the employee records in the Employee Test table.

### Phase 6 - Coalesce
Configured Employee ID as the Coalesce field to help prevent duplicate records and update existing records.

### Phase 7 - Insert and Update Data
Imported additional spreadsheet data and verified the transformation results.

### Phase 8 - Reports
Created reports for:
- Employees by Department
- Employees by Location
- Employee List

### Phase 9 - Dashboard
Created the Employee Analytics Dashboards dashboard and captured the dashboard configuration.

## Tools Used
- ServiceNow
- Import Sets
- Transform Maps
- ServiceNow Tables
- Reports and Dashboards
- Spreadsheet data

## Project Outcome
The project demonstrates importing employee data from a spreadsheet into ServiceNow using Import Sets and Transform Maps, with Coalesce configuration and reporting for the imported data.
